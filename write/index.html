Connect to GitHub

Your site is stored on GitHub. To let this page save posts there, GitHub gives you a personal key. You only do this once.

  1. Open the key page on GitHub. The name and the permission are already filled in.
  2. Under Repository access, choose Only select repositories and pick your site.
  3. Under Permissions, check that Contents is set to Read and write. Then click Generate token.
  4. Copy the key (it starts with github_pat_) and paste it below.

The key stays in this browser. It is sent to GitHub and nowhere else. You can remove it at any time under "My posts".
